# 太初灵契 · 正式美术与画面验收

这是实施规格与未完成项，不是成品验收证明。用户要求完整竖屏游戏，非原型、概念或简笔画；高精细手绘奇幻画面参考《圣兽之王》的清晰度与精细度，所有角色、场景、图标和音画资产必须原创或有明确许可。不得从参考游戏拆包或复制角色设计。

## 统一视觉语法

- 竖屏，左右阵营对峙，侧面偏三分之四、轻俯视。地面横向可读，不改成上下交战。
- 人物正常成年比例，脚落在同一视觉平面；轮廓分层为发型/肩部/武器/衣摆，避免职业只能靠文字区分。
- 笔触细腻、材质区分丝绸/皮革/金属/玉石；光源柔和明确，不能靠过度锐化和泛光伪造细节。
- 墨青、旧金与暖纸色为界面基调；控件既要精致也要可触达。小屏战场人物以轮廓和职业色识别，详情页展示原图细节。
- 人物背景真正透明，边缘无白圈、无裁切武器/头发/脚。统一身体显示高度，不按整张画布等宽强行拉伸；敌方镜像后文字/装备方向不产生明显错误。

## 制作和验收顺序

1. 人物设计和高精细全身原画；先补赤璃/叶流风职业辨识，随后给其他同职业人物独立资产，不能按职业复用宣布名册完成。
2. 统一比例、落脚点、武器边距与 alpha，生成引擎 SpriteFrame metadata，保留 UUID。
3. 实际游戏检查：720×1280 和常见长屏缩放；四人、六人、九人左右阵型；角色不重叠遮挡关键信息，姓名/生命值可读，详情页无拉伸。
4. 待机、攻击、施法、受击与倒下的动作/特效分层。当前整张静态图位移不是完整角色动画，不作为同等品质验收。
5. 法术目标与规则事件一致，音效与命中同步；控制同时特效数量、避免强闪烁。没有音频和动作实测时明确未完成。
6. 真实游戏截图与可重复交互验收，不用独立插画、静态排版或模型生成的假游戏截图替代。
